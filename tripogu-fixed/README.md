# Tripogu Next.js UI

Responsive Next.js App Router build inspired by the attached Tripogu desktop and mobile screens.

## Includes
- Login screen
- Home / map-first exploration screen
- Search suggestions and filters
- Routes list and route details
- Blog list and blog details
- Saved listings and saved routes
- Profile screen

## Run
```bash
npm install
npm run dev
```

## Notes
- Uses Material 3-inspired rounded surfaces, chips, and navigation patterns.
- Desktop and mobile layouts are both covered.
- Remote images are configured in `next.config.mjs`.
